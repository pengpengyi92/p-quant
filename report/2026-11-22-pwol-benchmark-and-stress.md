# PWOL 风格合成组合的基准比较与压力测试

**作者：Pengyi Peng｜时间：2026-11-22T16:54:18+08:00（Asia/Shanghai）**

**合成演示显示了两种相反结果。** 给原先有意校准到 50% 的路径加上合成基准，组合跑赢；在不拟合任何结果的新下跌路径，组合买入后亏损更多，回撤也比基准深。这验证的是评估和绘图链能忠实展示负结果，不是投资能力的统计证据。

| 同一情景内匹配 252 期 | 原校准演示 | 未校准下跌压力 |
| --- | ---: | ---: |
| 组合费后累计收益 | +50.00% | -24.96% |
| 合成基准累计收益 | +10.15% | -21.78% |
| 累计超额（收益差） | +39.85 pp | -3.18 pp |
| 相对累计复利（净值比） | +36.18% | -4.06% |
| 年化 OLS Alpha（算术） | +33.97% | -6.43% |
| OLS Beta | 0.68 | 0.90 |
| IR（年化主动收益／跟踪误差） | 5.83 | -0.67 |
| 年化跟踪误差 | 5.26% | 6.07% |
| 最大回撤：组合 / 基准 | -2.79% / -8.70% | -31.64% / -26.67% |
| 相对净值最大回撤 | -1.45% | -11.85% |

压力下组合落后 **3.18 个百分点**；它比同情景基准多下探 **4.97 个百分点**（各自最大回撤之差），相对净值最大回撤 **11.85%**。这三个数字分别描述终值差、各自最坏峰谷和相对于基准的最坏峰谷，不能互换。

## 合成基准和未拟合压力

- **原校准情景：**原组合沿用旧夹具及费用，253 个净值点（含起点）验证不变；基准共用它的随机冲击之一，另有未拟合的固定漂移与独立扰动。原组合仍是全路径有意校准，**+33.97% Alpha 和 5.83 IR 不是 OOS 结果**，也不是实际 PWOL 指标。
- **新下跌情景：**新种子，预设两段负向漂移冲击，共用系统冲击并各有扰动；组合沿用相同 21 期调仓、权重方案和 5 bp 成交费用。没有目标收益、Sharpe 或回撤，也没挑“最好种子”。这是一条刻意的合成压力路径，不是随机市场样本的平均表现。
- **共同边界：**两条基准均是对应情景的无费用合成指数，不是市场指数或可交易工具，比较保留组合费用差。Alpha/Beta 对对应基准做同期日超额收益 OLS，Alpha 将日截距乘 252（算术年化）；IR 分母是日主动收益的样本波动率按 √252 年化。详见 [pevluation 的统一口径](../pevluation/README.md)。
