# PWOL 风格合成组合的回测、指标与图

**作者：Pengyi Peng｜时间：2026-11-22T16:48:16+08:00（Asia/Shanghai）**

这份报告验证三段工程链：按同一账本从合成输入生成成交和净值，独立计算指标，再把结果绘为净值、回撤、分期净收益和换手。**没有使用 PWOL 持仓、行情或真实收益。50.00% 和 5.00 是全期校准目标，不是预测或 OOS 证据。**

| 结果 | 值 |
| --- | ---: |
| 252 期费后累计收益／CAGR | 50.00%／50.00% |
| 年化 Sharpe／Sortino（无风险为 0） | 5.00／9.06 |
| 年化波动 | 8.18% |
| 最大回撤／最长回撤期 | −2.79%／17 期 |
| 正收益期占比／日度利润因子 | 63.89%／2.19 |
| 双边换手（不含首次建仓） | 153.10%（半双边折算 76.55%） |
| 调仓、成交与总模拟费用 | 含建仓共 12 次、24 笔、1,459.32 虚拟货币单位 |

权重在 53.5/46.5 与 46.5/53.5 双方向交替；两个袖珍资产共享可校准的漂移与波动，并加入对称的资产差异噪声。持仓在非调仓期自然漂移。开盘假设等于上期收盘，费率 5 bp，未模拟盘中跳空、滑点、容量或真实流动性。从期初现金开始，初次建仓近 100% 的双边换手另列，避免误读。终值从 1,000,000 到 1,500,000 均为合成单位。
