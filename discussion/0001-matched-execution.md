# 同一份信号在两个回测引擎上为什么不同

**作者：Pengyi Peng｜时间：2026-11-22T15:35:56+08:00（Asia/Shanghai）｜状态：OPEN**

即便信号一致，一个引擎在信号收盘成交、一个在下一交易期开盘成交，就已经是在跑两个策略。长短仓、成交优先级、复权、价格缺失、手续费或资金共享也会改变账本。

第一个要回答的问题：能否让各引擎用完全相同的事件和订单输入，逐行复现手算账本？优先对齐 [合成回测协议](../project/synthetic-backtest-comparison/README.md)；公开记录分歧、输入与失败原因。性能和现实交易可用性是后续问题。
